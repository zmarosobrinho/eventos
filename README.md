# Sistema de Frases (PHP + MySQL)

1. Importe o arquivo `banco.sql` no phpMyAdmin para criar as tabelas.
2. Edite o arquivo `conexao.php` com host, banco, usuário e senha do seu MySQL.
3. Envie todos os arquivos por FTP para a pasta desejada do seu site.
4. Acesse `index.php` (menu completo) ou `live.php` (uso durante a live) no navegador.
